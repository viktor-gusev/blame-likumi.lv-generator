# blame-likumi-lv

`blame-likumi-lv` builds ordinary Git histories from official law and Cabinet
regulation versions published by [Likumi.lv](https://likumi.lv). The active
catalog contains Saeima laws and Ministru kabineta noteikumi; standalone
amendment acts are excluded by the official catalog filter. Raw HTML files are
kept only in the local, ignored `cache/` directory.

## Quick start

Python 3.11+ and Git are required.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
blame-likumi catalog
blame-likumi fetch --workers 4
blame-likumi build
blame-likumi verify --workers 4
```

Full pipeline:

```powershell
blame-likumi generate
```

The default configuration is `config/active-documents.json`, generated by
`catalog`. The generated repository is created at `../latvian-laws` and can be
changed with `--output`. To develop against one document:

```powershell
blame-likumi generate --law 45467 --output ../latvian-laws-one
```

## Catalog and cache

`catalog` reads active documents from Likumi.lv's public catalog endpoint and
writes a deterministic configuration. `cache/` makes repeated runs resumable
and avoids downloading data that is already available locally. Use `--refresh`
when a complete catalog refresh is needed.

`--workers 4` starts four independent document workers, each with its own rate
limit. For the most conservative crawl, keep the default value of `1`.

The generator repository intentionally does not commit downloaded source pages
or the generated legal-act repository.

## Architecture

- `catalog.py` discovers active laws and Cabinet regulations.
- `html_parser.py` extracts official document text, metadata and revision dates.
- `normalize.py` provides deterministic normalization for build and verify.
- `fetcher.py` implements cache, rate limiting, retries and backoff.
- `git_history.py` groups snapshots by effective date and creates historical commits.
- `verification.py` compares generated HEAD with the current official version.
